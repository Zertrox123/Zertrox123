### À propos de moi

Étudiant en informatique passionné par le bas niveau, la recompilation statique, les systèmes Unix/macOS et l'IA
Je dev principalement en C, C++20, Rust et Python sur des recompilateurs x86/x64 → ARM64, des projets système/réseau et du machine learning
